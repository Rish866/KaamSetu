# KaamSetu v1.4.0

Production marketplace release. All demo data removed.

**Candidates:** job search with filters and sorting, saved jobs, job detail with explainable match score, apply with note, withdraw,
application timeline, interview confirm/decline/reschedule, invitations, notification centre, full profile (headline, locations ranked,
work modes, salary, experience, education, certifications, languages, skills, optional photo), private resume upload with checksum
duplicate detection, consent controls, data export, account deletion request, password and email change, sign out of all devices.

**Employers:** company workspace, verification with GSTIN/CIN/LLPIN/domain and document upload, company profile, team invites and roles,
job drafts, edit, submit for review, pause, resume, close, reopen, duplicate, job history, applicants with search and stage filter,
validated pipeline, interviews, offers, rejections with reasons, consent-gated contact details, candidate discovery and invitations,
dashboard from live data.

**Administrators:** role-based console (admin, moderator, support, privacy) for company verification, job moderation, abuse reports,
user lookup and suspension, deletion processing, failed emails, audit search, role management and versioned matching weights.

**Security:** least-privilege grants, hardened RLS, audited and immutable history, server-enforced password policy (on config push),
web security headers, neutral authentication messages. 65 database tests, 9 unit tests, 32 browser tests.

**Upgrade note:** older test APKs (v1.3.0) can no longer apply or post jobs after the database update. Install v1.4.0.
