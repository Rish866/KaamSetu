# KaamSetu v1.5.0

Android app (APK) matching the live website and the production database (schema 202611270004).

## What's in this version
* Pan-India locations: search and discovery by state, district, city, area and PIN code.
* Offer and joining records confirmed by both sides (joined, day 15, day 30), with disputes decided by KaamSetu.
* Employer reliability scorecard, review commitment and verification method (GSTIN/CIN, number never shown).
* Neutral reasons when an application or hire ends; readiness questions before applying.
* Settings → "Who used your data": every access to your profile, with one-tap withdrawal.
* Relocation and office-day preferences; optional job alerts (off by default).
* Zero-fee reminders: KaamSetu never asks candidates for money.

## Install (Android)
Download `KaamSetu.apk` below (or from https://www.getkaamsetu.in/download), open it and allow your browser to install it.
Installing over an older KaamSetu test build keeps your account; if Android refuses the update, uninstall the old app first.

## Not included
* iPhone: no App Store build yet (needs an Apple Developer account). The iOS Simulator file is for testing on a Mac only; iPhone users should use the website.
* Play Store: not published yet.
